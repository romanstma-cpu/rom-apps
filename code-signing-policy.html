Verification information, product requirements and a direct route to support.

Installer signing

The Windows installers linked from ROM Apps are not yet code-signed. Windows may show an unknown-publisher warning. ROM does not ask you to turn off antivirus protection or make a security exception.

A checksum match confirms that the file matches the published installer. It does not establish that the software is safe or suitable for your use.

Verify ROM Polybot 2.8

Download the Windows installer and its SHA-256 checksum. If the installer is in your Downloads folder, this PowerShell command compares them:

$file = Join-Path ([Environment]::GetFolderPath('UserProfile')) 'Downloads\ROM-Polybot-Setup-2.8.0.exe'
$expected = (Invoke-RestMethod 'https://romapps.xyz/assets/SHA256SUMS-Polybot-2.8.0.txt').Trim().Split(' ')[0]
$actual = (Get-FileHash -LiteralPath $file -Algorithm SHA256).Hash
if ($actual -eq $expected) { 'MATCH' } else { 'DOES NOT MATCH — do not install this file' }

If you saved the installer elsewhere, change the file path. This installer is for Windows 10/11 (64-bit). It includes its Python runtime and does not need a separate Python installation.

Other downloads

  • ROM Nova releases — Windows downloads; the browser app is also available.
  • ROM Trader releases — Kalshi desktop app.
  • ROM Scribe releases — offline transcription app.

Use the checksum attached to the matching release when verifying these apps. Do not compare checksums from different versions.

Before connecting a trading account

Polybot needs your Polymarket US Key ID and Secret Key. Credentials are encrypted locally with your Windows account. Trading starts paused. Its main-strategy execution checks are not a guarantee of profit, and live authenticated trading remains unverified for this release.

Nova does not execute trades. Trader starts in paper mode; its published seven-strategy study found losses after fees. Review each app’s settings and limitations before using it with funds.

Get help

For Polybot or website issues, open a support issue. For other apps, use their own project: Nova, Trader, or Scribe.

Include the app version and a description of the problem. Never post API keys or secret keys in a public issue.
