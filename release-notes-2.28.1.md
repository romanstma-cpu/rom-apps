# ROM PolyBot 2.28.1

This release makes the desktop workspace easier to scan and easier for a new
user to complete setup.

- Trade Readiness now highlights the four controls that affect the next entry,
  with account detail and additional safeguards available on demand.
- Status values use consistent ready, warning, profit, and loss colors.
- The Strategy page now offers a direct **Connect your API** action whenever a
  missing Polymarket US API connection prevents starting practice or live mode.

Trading logic, saved settings, order routing, and risk controls are unchanged.
The Windows installer is unsigned and the Apple Silicon installer is not
Apple-notarized. Verify downloads against the published SHA-256 files.
