# ROM PolyBot 2.28.1

This Windows release makes the desktop workspace easier to scan and easier for a new user to complete setup.

- Trade Readiness puts the four controls that affect the next entry first.
- Supporting account safeguards remain available without crowding the main view.
- The Strategy page gives an unconnected user a direct path to Polymarket US API setup.

Trading logic, saved settings, order routing, and risk controls are unchanged.
