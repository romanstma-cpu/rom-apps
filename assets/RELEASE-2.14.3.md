# ROM Polybot 2.14.3

Windows and macOS downloads include slightly larger compact controls and more space around expandable settings. Trading rules and saved risk limits are unchanged.

Mac downloads are separate for Apple Silicon and Intel. Both target macOS 15 or later and bundle Python; you do not need a separate Python installation. Open the disk image and drag ROM PolyBot to Applications.

These Mac builds are not Apple-notarized. Review https://support.apple.com/102445 before opening an unidentified-developer app. Do not ignore damage or malware warnings. Verify the download using POLYBOT-MAC-CHECKSUMS-2.14.3.txt.

Validation: TypeScript and Windows production build passed; isolated layout and live-start checks passed. Each Mac build must pass the packaged backend self-test, disk-image verification, and packaged renderer/backend startup test before its link is published. No live trading was performed.
