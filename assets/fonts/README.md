# Space Grotesk

`space-grotesk-latin-variable.woff2` is the normal-style Latin subset of Space
Grotesk, served by Google Fonts for the requested variable weight range 400–700.
It is self-hosted so the homepage does not contact a third-party font server.

- Downloaded on 2026-09-25.
- Google Fonts stylesheet: https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400..700&display=swap
- Unmodified font source: https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4Cw.woff2
- License source: https://raw.githubusercontent.com/google/fonts/main/ofl/spacegrotesk/OFL.txt
- Font authors: https://github.com/floriankarsten/space-grotesk
- License: SIL Open Font License 1.1, preserved in `Space-Grotesk-OFL.txt`.

Use `font-weight: 400 700`, `font-style: normal`, and `font-display: swap` in the
`@font-face` declaration. The Latin subset includes English and common Western
European text; retain a system fallback for characters outside this subset.
