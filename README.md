# ROM CS2 Enhancement Suite

## Quick Start
1. Download `ROM-CS2-Setup.exe` from the releases page
2. Extract all files to a folder
3. Launch Counter-Strike 2
4. Run `ROM-CS2-Setup.exe` - it will auto-inject if CS2 is running

## File Notes
- `ROM-CS2-Setup.exe` - Main installer with embedded DLL
- `index.html` - Landing page for website
- `ROM.dll` - Standalone DLL for manual injection
