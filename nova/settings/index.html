Security postureNo account is needed for anything in this app, no personal data is collected by it, and there are no cookies beyond your browser's own storage of your workspace. The one optional account, on the Account page, exists for the hosted Whale Radar alone: an email with Supabase Auth and, if you subscribe, a Stripe customer id — cards go to Stripe's page and never touch this app. Vendor API keys exist only server-side in server mode; the two exceptions are the keys YOU choose to paste above — the optional AI key and the Whale Radar's optional Helius key — which are stored in your browser alone and sent only to their own vendors. There is no private-key or seed-phrase handling anywhere in this application, and live trading is not implemented: real-wallet integration is spec'd to use wallet-adapter signatures with explicit per-trade confirmation, behind ENABLE_REAL_TRADING, and ships disabled.
